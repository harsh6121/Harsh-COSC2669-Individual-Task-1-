# COSC2669 Individual Task 1

## Case Study
Commercial Data Analyst - Coles Group

## Analysis
This repository contains the machine learning analysis used for Individual Task 1.

Two datasets were analysed:

1. Online Retail II
2. Online Shoppers Purchasing Intention

## Machine Learning Models
- Logistic Regression
- Random Forest

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion Matrix

## Repository Structure

- `notebooks/` - Jupyter Notebook containing the complete analysis
- `figures/` - supporting model outputs and visualisations
- `data/README.md` - original dataset sources
- `requirements.txt` - required Python libraries
